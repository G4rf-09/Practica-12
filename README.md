# Games - Tienda de videojuegos

Página web de una tienda de videojuegos enfocada en Nintendo, que también vende productos de PlayStation y Xbox: consolas, videojuegos físicos, accesorios y amiibos.

## Páginas

- **index.html**: inicio con categorías, historia, misión, visión y contacto.
- **catalogo.html**: catálogo de productos desde MockAPI. Al comprar se resta el stock.
- **login.html**: acceso al panel con usuario y contraseña definidos en el código.
- **admin.html**: panel de administración con el CRUD de productos.

## Tecnologías

- HTML5, CSS3 y JavaScript (fetch)
- Bootstrap 5 y Bootstrap Icons
- MockAPI.io (recursos `productos` y `categorias`)
- GitHub Pages
